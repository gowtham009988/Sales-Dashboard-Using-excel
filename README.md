# Supermarket Sales Analysis Dashboard 📊| Excel🧑‍💻

## Project Overview
This project focuses on analyzing supermarket sales data and building an interactive Excel dashboard to monitor business performance and identify meaningful sales insights.📈

The dashboard transforms raw sales data into visual reports, helping users understand sales trends, profitability, customer behavior, and product category performance.

## Objectives
- Analyze overall supermarket sales performance.
- Track total sales, profits, and transaction counts.
- Understand sales performance across different product categories.
- Analyze customer purchasing patterns.
- Evaluate sales performance across different branches and cities.
- Present business insights through an interactive dashboard.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization
- Excel Dashboard

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Transaction Count
- Quantity Sold
- Average Customer Rating
- Sales by Product Category
- Sales trends and performance analysis
- Customer type and payment method analysis
- Branch and city-wise sales analysis
